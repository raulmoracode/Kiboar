Commands

Run from the repository root. Start the stack first, then open a card above. Dev commands print only the URL table and log to .dev-logs/.

Start

pnpm dev / pnpm dev:all
Every server product and PostgreSQL. Prints every URL.
pnpm dev:web
Web only.
pnpm dev:docs
Documentation only.
pnpm dev:shop
PostgreSQL, Medusa, the storefront and the POS.
pnpm dev:api
PostgreSQL and Medusa.
pnpm dev:storefront
PostgreSQL, Medusa and the storefront.
pnpm dev:pos
PostgreSQL, Medusa and the POS.
pnpm dev:studio
The Studio desktop app through Tauri.

Shop commands need the three local env files and Docker (or Colima). Seed the catalogue with pnpm --filter @kiboar/shop seed.

Check and build

pnpm lint
Biome lint and format check for the whole repository.
pnpm lint:docs
Biome only for the documentation site.
pnpm lint:studio
Biome only for Studio.
pnpm lint:fix
Apply safe Biome fixes and formatting.
pnpm typecheck
TypeScript in every package.
pnpm test
Unit tests through Turbo.
pnpm test:e2e
Browser end-to-end suites.
pnpm build
Production builds through Turbo.
pnpm check
Full gate: library, lint, Rust lint, typecheck, unit tests, build, Rust tests and the Studio check.

Rust

pnpm lint:rust
rustfmt and clippy; warnings are errors.
pnpm test:rust
Rust workspace tests.
pnpm check:rust
cargo check for the Studio application.

Library and schemas

pnpm library
Python library checks and tests: lint, courtyards, symbols, inventory and provenance.
pnpm schema:export
Regenerate the JSON Schema from the Zod source.

Setup

pnpm install
Install the workspace once.
pnpm prepare
Runs after install and installs the Husky Git hooks.
