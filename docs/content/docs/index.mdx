title: Kiboar

Kiboar is a component library for mechanical keyboards in **KiCad 10**: 146
symbols, 1332 footprints in 23 libraries, and 3D models for most of them.

## Start here

- [Install with the Plugin and Content Manager](/docs/install/pcm)
- [Install from a clone](/docs/install/clone)
- [Browse the libraries](/docs/libraries)

## What is inside

| | |
| --- | ---: |
| Symbols | 146 |
| Footprints | 1332 |
| Footprint libraries | 23 |
| 3D models | 204 |

Every placed-part footprint carries a courtyard, so KiCad's design rules checker
reports overlapping parts before you send the board out.
