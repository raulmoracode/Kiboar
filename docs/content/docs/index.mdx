Kiboar is a component library for mechanical keyboards in **KiCad 10**. It puts
the parts a keyboard needs — switches, microcontrollers, connectors, displays —
in one symbol library, one footprint library per family, and a STEP model for
almost every part.

## What is inside

| | |
| --- | ---: |
| Symbols | 146 |
| Footprints | 1332 |
| Footprint libraries | 23 |
| 3D models | 204 |

- **Switches** — MX and Choc footprints, plus CAD-only variants for plates.
- **MCUs** — Pro Micro, Elite-C, nice!nano, RP2040, STM32, ESP32, Pico and
  XIAO boards, with their pin headers.
- **Connectors** — USB-C, TRRS, battery holders and jacks, Ethernet, pin headers.
- **The rest** — encoders, OLED displays, buzzers, LEDs, buttons, DIP switches,
  joysticks, mounting holes and board cutouts.

## How it is organised

| Path | Contents |
| --- | --- |
| `symbols/Kiboar.kicad_sym` | One symbol library, one reference prefix per family (`SW`, `U`, `J`, `D`, `BT`, `DS`). |
| `footprints/Kiboar_<family>.pretty` | One footprint library per family. |
| `3dmodels/Kiboar_<family>.3dshapes` | STEP models, referenced as `${KIBOAR_3DMODELS}/Kiboar_<family>.3dshapes/<name>.step`. |

Every placed-part footprint carries a courtyard, and its `attr` matches its pads,
so KiCad's design rules checker flags overlapping parts before you order the
board.
