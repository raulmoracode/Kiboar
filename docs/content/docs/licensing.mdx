Kiboar is a **mixed-licence collection**.

- The original work in this repository — the symbols, footprints and models
  designed here, the tools and the docs — is **MIT**.
- CAD data collected from other projects keeps its own licence.

`NOTICE` in the repository root lists every verified origin, the affected files
and the evidence.

## Before using it commercially

- The ScottoKeebs models and three footprints are **CC BY-NC-SA 4.0**: no
  commercial use.
- Ten symbols are SnapEDA imports under **CC BY-SA 4.0** with the Design
  Exception, so they need attribution when the files themselves are
  redistributed.
- The switch, hotswap, cutout and stabilizer models are from the Keyswitch KiCad
  Library, dual **MIT / CC BY-SA 4.0**, and can be used under MIT.

If you need a commercially clean library, review `NOTICE` and exclude the
non-commercial subset.
