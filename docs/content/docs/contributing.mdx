The long form is in [`CONTRIBUTING.md`](https://github.com/raulmoracode/Kiboar/blob/main/CONTRIBUTING.md).
The short version:

## Workflow

<Steps>
<Step>

Open or reuse an issue, then create a branch `fix/<issue>-<slug>` or
`feat/<issue>-<slug>`.

</Step>
<Step>

Add the footprint to the matching `Kiboar_*.pretty` library, with a courtyard
and an `(attr ...)` that matches the pads.

</Step>
<Step>

Add the symbol with `Manufacturer`, `MPN`, `ki_keywords` and a
`ki_fp_filters` that matches the footprint.

</Step>
<Step>

Run the checks:

```bash
python3 tools/lint.py
python3 tools/gen_courtyard.py --check
python3 tools/normalize_symbols.py --check
python3 tools/model_inventory.py --check
```

</Step>
<Step>

Open a pull request with the command output, not a claim.

</Step>
</Steps>

<Callout type="info">
New CAD data needs its origin and licence recorded in `NOTICE`.
</Callout>
