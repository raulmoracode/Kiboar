title: Plugin and Content Manager

---

Kiboar ships as a library package: one ZIP that the Plugin and Content Manager
(PCM) installs into `${KICAD10_3RD_PARTY}` and registers in your global tables.

## Build the ZIP

```bash
python3 tools/build_pcm.py
```

The default build matches KiCad's default nickname prefix (`PCM_`). If you
cleared **Preferences → Packages and Updates → Library nickname prefix**, build
the other variant:

```bash
python3 tools/build_pcm.py --no-prefix
```

## Install

1. Open **Tools → Plugin and Content Manager → Install from File…**.
2. Choose `dist/Kiboar-1.0.0.zip` (or `-no-prefix.zip`).
3. Apply the pending changes.

The package rewrites the model paths to
`${KICAD10_3RD_PARTY}/3dmodels/com_github_raulmoracode_kiboar/`, so the 3D
viewer works without setting any variable.

## Not in the official repository yet

The package is not listed in the PCM repository. Until it is, use **Install from
File** with a ZIP built from this repository, or the clone route.
