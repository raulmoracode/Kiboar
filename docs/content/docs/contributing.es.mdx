---
title: Contribuir
description: Cómo añadir un componente.
---

La versión larga está en [`CONTRIBUTING.md`](https://github.com/raulmoracode/Kiboar/blob/main/CONTRIBUTING.md).
La corta:

1. Abre o reutiliza una issue y crea una rama `fix/<issue>-<slug>` o
   `feat/<issue>-<slug>`.
2. Añade el footprint a la librería `Kiboar_*.pretty` que corresponda, con
   courtyard y un `(attr ...)` que coincida con los pads.
3. Añade el símbolo con `Manufacturer`, `MPN`, `ki_keywords` y un
   `ki_fp_filters` que coincida con el footprint.
4. Ejecuta las comprobaciones:

```bash
python3 tools/lint.py
python3 tools/gen_courtyard.py --check
python3 tools/normalize_symbols.py --check
python3 tools/model_inventory.py --check
```

5. Abre un pull request con la salida de los comandos, no con una afirmación.

Los datos CAD nuevos necesitan su origen y licencia en `NOTICE`.
