La corta:

## Flujo de trabajo

<Steps>
<Step>

Abre o reutiliza una issue y crea una rama `fix/<issue>-<slug>` o
`feat/<issue>-<slug>`.

</Step>
<Step>

Añade el footprint a la librería `Kiboar_*.pretty` que corresponda, con
courtyard y un `(attr ...)` que coincida con los pads.

</Step>
<Step>

Añade el símbolo con `Manufacturer`, `MPN`, `ki_keywords` y un
`ki_fp_filters` que coincida con el footprint.

</Step>
<Step>

Ejecuta las comprobaciones:

```bash
python3 library/tools/lint.py
python3 library/tools/gen_courtyard.py --check
python3 library/tools/normalize_symbols.py --check
python3 library/tools/model_inventory.py --check
```

</Step>
<Step>

Abre un pull request con la salida de los comandos, no con una afirmación.

</Step>
</Steps>

<Callout type="info">
Los datos CAD nuevos necesitan su origen y licencia en `NOTICE`.
</Callout>
