Kiboar es una librería de componentes para teclados mecánicos en **KiCad 10**:
146 símbolos, 1332 footprints en 23 librerías y modelos 3D para la mayoría.

## Empieza aquí

- [Instalar con el Plugin and Content Manager](/es/docs/install/pcm)
- [Instalar desde un clon](/es/docs/install/clone)
- [Ver todas las librerías](/es/docs/libraries)

## Qué contiene

| | |
| --- | ---: |
| Símbolos | 146 |
| Footprints | 1332 |
| Librerías de footprints | 23 |
| Modelos 3D | 204 |

Cada footprint de una pieza lleva courtyard, así que el comprobador de reglas
de KiCad avisa de las piezas solapadas antes de enviar la placa a fabricar.
