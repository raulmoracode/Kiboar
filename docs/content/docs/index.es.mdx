Kiboar es una librería de componentes para teclados mecánicos en **KiCad 10**.
Reúne las piezas que necesita un teclado —interruptores, microcontroladores,
conectores, pantallas— en una sola librería de símbolos, una librería de
footprints por familia y un modelo STEP para casi todas las piezas.

## Qué contiene

| | |
| --- | ---: |
| Símbolos | 146 |
| Footprints | 1332 |
| Librerías de footprints | 23 |
| Modelos 3D | 204 |

- **Interruptores** — footprints MX y Choc, y variantes solo CAD para placas.
- **MCUs** — placas Pro Micro, Elite-C, nice!nano, RP2040, STM32, ESP32, Pico y
  XIAO, con sus tiras de pines.
- **Conectores** — USB-C, TRRS, portapilas y conectores de pila, Ethernet,
  tiras de pines.
- **El resto** — encoders, pantallas OLED, zumbadores, LEDs, pulsadores,
  interruptores DIP, joysticks, taladros de montaje y recortes de placa.

## Cómo está organizado

| Ruta | Contenido |
| --- | --- |
| `symbols/Kiboar.kicad_sym` | Una librería de símbolos, un prefijo de referencia por familia (`SW`, `U`, `J`, `D`, `BT`, `DS`). |
| `footprints/Kiboar_<family>.pretty` | Una librería de footprints por familia. |
| `3dmodels/Kiboar_<family>.3dshapes` | Modelos STEP, referenciados como `${KIBOAR_3DMODELS}/Kiboar_<family>.3dshapes/<name>.step`. |

Cada footprint de una pieza lleva courtyard, y su `attr` coincide con sus pads,
así que el comprobador de reglas de KiCad avisa de las piezas solapadas antes de
enviar la placa a fabricar.
